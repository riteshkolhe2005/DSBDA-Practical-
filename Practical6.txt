Important Concepts

What is Naive Bayes?

Naive Bayes is a probabilistic supervised learning algorithm based on Bayes theorem.

Why is it called Naive?

Because it assumes all features are independent from each other.

Gaussian Naive Bayes

Gaussian Naive Bayes is used when numerical data follows normal distribution.

Bayes Theorem

Bayes theorem calculates probability of an event based on prior knowledge.

Feature Scaling

Feature scaling standardizes data for better model performance.

Confusion Matrix

Confusion matrix evaluates classification performance.

Accuracy

Accuracy is percentage of correct predictions.

Precision

Precision measures correctness among predicted positive values.

Recall

Recall measures correctly predicted actual positive values.

Bayes Theorem Formula

Bayes Theorem:

P(A|B) = [P(B|A) × P(A)] / P(B)

Where: P(A|B) = Posterior Probability P(B|A) = Likelihood P(A) = Prior Probability P(B) = Evidence

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
data=pd.read_csv("Iris.csv")
X=data.iloc[:,:4].values
y = data['Species'].values
print(data.head())
from sklearn.model_selection import train_test_split
# Imports function used to divide dataset.
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3)
# Dataset is divided into:
#     Training Data → used to train model
#     Testing Data → used to test model
from sklearn.preprocessing import StandardScaler
sc = StandardScaler()
# It converts data into a standard form:
# Mean = 0
# Standard Deviation = 1
X_train = sc.fit_transform(X_train)
# fit() calculates mean and standard deviation, and transform() scales the data using those values.
X_test = sc.transform(X_test)
# z=x-u/rho
# transform() is used to convert the original data into scaled/standardized form using previously learned values.
from sklearn.naive_bayes import GaussianNB
classifier = GaussianNB()
# This line creates a Gaussian Naïve Bayes model object.
classifier.fit(X_train, y_train)
# This line is used to train the Naïve Bayes model using the training dataset.
y_pred = classifier.predict(X_test)
# This line is used to predict the output/classes for the test dataset using the trained Naïve Bayes model.
print(y_pred)
from sklearn.metrics import confusion_matrix
cm=confusion_matrix(y_test, y_pred)
from sklearn.metrics import accuracy_score
print("Consusion matrix: \n")
print(cm)
df = pd.DataFrame({'Real Values':y_test, 'Predicted Values':y_pred})
print(df)
from sklearn.metrics import precision_score, recall_score,accuracy_score
m=accuracy_score(y_test,y_pred)
print("Accuracy: {:.2f}".format(accuracy_score(y_test, y_pred)))
# How many predictions were correct out of total predictions.
print("Error Rate: {:.2f}".format(1 - m))
# How many predictions were wrong out of total predictions.
print("Precision: {:.2f}".format(precision_score(y_test, y_pred, average='micro')))
# Out of all predicted positive values, how many were actually correct.
print("Recall: {:.2f}".format(recall_score(y_test, y_pred, average='micro')))
# Out of all actual positive values, how many were correctly identified.
