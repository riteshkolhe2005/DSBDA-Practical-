Important Concepts

What is Data Preprocessing?

Data preprocessing is the process of cleaning and transforming raw data before applying machine learning algorithms.

Why Handle Missing Values?

Machine learning algorithms cannot work properly with null values. Missing values are handled using mean, median, mode, or by dropping rows.

Normalization

Normalization scales all values into a common range. Min-Max scaling converts values between 0 and 1.

Label Encoding

Label encoding converts categorical text labels into numerical values.

One Hot Encoding

One hot encoding creates separate binary columns for each category and avoids priority issues.

Difference Between Mean, Median, and Mode

Mean is average value, median is middle value, and mode is most frequent value.

Normalization Formula

Min-Max Scaling Formula:

Normalized Value = (X - Xmin) / (Xmax - Xmin)

Ans. It removes ordinal relationship between categories.

Ans. Overfitting occurs when a model learns training data too well and performs poorly on new data.

Ans. Mean is used because it represents average distribution of numerical data.

Q. What does inplace=True mean?

from sklearn import preprocessing

# Normalization->Mapping all Nominal value into Uniform Scale
    # Method->Min-Max Scaling ->Converts values between range 0 and 1.

x=df[['SepalLengthCm','SepalWidthCm','PetalLengthCm','PetalWidthCm']]
# Selects numerical columns from dataset.
min_max_scaler=preprocessing.MinMaxScaler()
# Creates Min-Max normalization object.
x_scaled=min_max_scaler.fit_transform(x)
# values become in range 0 to 1
dataframe=pd.DataFrame(x_scaled)
print(dataframe)
# Need of Normalization ->
# We do normalization because machine learning algorithms perform better when all features are on a similar scale.
label_encoder=preprocessing.LabelEncoder()
# creates label_encoder Object

df['Species']=label_encoder.fit_transform(df['Species'])
print(df['Species'])
print(df)
enc=preprocessing.OneHotEncoder()
# Label encoding converts the data in machine-readable form, but it assigns
# a unique number(starting from 0) to each class of data. This may lead to the
# generation of priority issues in the data sets
# Creates separate binary columns for each category.
new_df=df.drop(columns=['Species'])
enc_df=pd.DataFrame(enc.fit_transform(df[['Species']]).toarray())
df_encode=new_df.join(enc_df)
df_encode
