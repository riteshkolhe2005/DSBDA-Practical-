Important Concepts

What is Data Visualization?

Data visualization is the graphical representation of data using plots and charts.

Histogram

Histogram shows frequency distribution of numerical data.

Scatter Plot

Scatter plot shows relationship between two numerical variables.

Box Plot

Box plot shows median, quartiles, spread, and outliers of data.

Heatmap

Heatmap visually represents correlation values using colors.

Correlation

Correlation measures relationship strength between variables.

Positive Correlation

When one variable increases and another also increases.

Negative Correlation

When one variable increases while another decreases.

Outliers

Outliers are extreme values different from most observations.

Correlation Value Range

Correlation Value Meaning

+1 Perfect positive correlation

0 No correlation

-1 Perfect negative correlation

import pandas as pd
import numpy as np
from sklearn.preprocessing import MinMaxScaler, StandardScaler
from scipy import stats
#2. Load academic dataset
df = pd.read_csv("StudentsPerformance.csv")
df
df.columns
print(df.isnull().sum())
# Fill missing numerical values with mean
df.fillna(df.mean(numeric_only=True), inplace=True)
# Remove duplicate rows
df.drop_duplicates(inplace=True)
# Standardize column names
df.columns = df.columns.str.strip()
# 4. Describe dataset
print(df.head())
print(df.shape)
print(df.columns)
df.describe()
# 5. Identify outliers using IQR method
# Select numerical columns
numeric_cols = df.select_dtypes(include=[np.number])
Q1 = numeric_cols.quantile(0.25)
Q3 = numeric_cols.quantile(0.75)
IQR = Q3 - Q1
outliers = ((numeric_cols < (Q1 - 1.5 * IQR)) |
            (numeric_cols > (Q3 + 1.5 * IQR)))
print("Outliers using IQR:")
print(outliers.sum())
# 6. Identify outliers using Z-score method
z_scores = np.abs(stats.zscore(numeric_cols))
print("Outliers using Z-score:")
print((z_scores > 3).sum(axis=0))
# 7. Apply data transformation
# Log transformation
df_log = numeric_cols.apply(lambda x: np.log1p(x))
# Normalization using Min-Max Scaling
scaler = MinMaxScaler()
df_normalized = pd.DataFrame(scaler.fit_transform(numeric_cols),
                             columns=numeric_cols.columns)
# 8. Display transformed data
print("Log Transformed Data:")
print(df_log.head())
print("Normalized Data:")
print(df_normalized.head())
