Important Concepts

What is Data Visualization?

Data visualization graphically represents information for easier understanding.

Histogram

Histogram shows distribution and frequency of numerical data.

Scatter Plot

Scatter plot displays relationship between two numerical variables.

Box Plot

Box plot identifies spread, quartiles, and outliers.

Heatmap

Heatmap visually represents correlation using colors.

Pairplot

Pairplot shows pairwise relationships among features.

Distribution Plot

Distribution plot shows spread and shape of data.

Correlation

Correlation measures relationship strength between variables.

Outliers

Outliers are extreme values significantly different from other observations.

Correlation Interpretation

Correlation Value Interpretation

+1 Perfect positive relationship

0 No relationship

-1 Perfect negative relationship

import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
titanic = pd.read_csv("titanic.csv")
titanic.head()
sns.countplot(x='sex', hue='survived', data=titanic)
plt.title("Survival Count by Gender")
plt.show()
print(titanic['age'].isnull().sum())
sns.boxplot(x=titanic['age'])
plt.title("Boxplot of Age")
plt.show()
sns.boxplot(x='sex', y='age', hue='survived', data=titanic)
plt.title("Age vs Gender vs Survival")
plt.show()
Q1 = titanic['age'].quantile(0.25)
Q3 = titanic['age'].quantile(0.75)
IQR = Q3 - Q1
lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR
outliers = titanic[(titanic['age'] < lower) | (titanic['age'] > upper)]
print("Outliers in Age:\n")
print(outliers[['age', 'sex', 'survived']])
