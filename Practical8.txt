Important Concepts

What is Data Visualization?

Data visualization represents data graphically for better understanding.

Histogram

Histogram shows frequency distribution of numerical data.

Scatter Plot

Scatter plot shows relationship between two variables.

Box Plot

Box plot displays quartiles, median, spread, and outliers.

Bar Plot

Bar plot compares categorical values using bars.

Line Graph

Line graph shows trends over time or sequence.

Heatmap

Heatmap displays correlation values using color intensity.

Correlation

Correlation measures relationship between variables.

Outliers

Outliers are extreme values different from most data points.

Correlation Range

Correlation Value Meaning

+1 Perfect positive correlation

0 No correlation

-1 Perfect negative correlation

import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
titanic = pd.read_csv("titanic.csv")   # use your file path
titanic.head()
sns.countplot(x='survived', data=titanic)
plt.title("Survival Count")
plt.show()
# It shows:
# how many passengers survived
# how many did not survive
sns.countplot(x='sex', hue='survived', data=titanic)
plt.title("Survival by Gender")
plt.show()
sns.countplot(x='pclass', hue='survived', data=titanic)
plt.title("Survival by Class")
plt.show()
# 🔹 4. Histogram for Fare Distribution
sns.histplot(titanic['fare'], bins=30, kde=True)
plt.title("Fare Distribution")
plt.xlabel("Fare")
plt.ylabel("Frequency")
plt.show()
# A histogram is a graph used to show the distribution of numerical data.
skew_value = titanic['fare'].skew()
print("Skewness of Fare:", skew_value)
print("Mean Fare:", titanic['fare'].mean())
print("Median Fare:", titanic['fare'].median())
titanic['fare'].describe()
